## 📖 Descripción del Proyecto
Este proyecto es una práctica de clase que consiste en la creación de un portafolio web personal utilizando **HTML5** y **CSS3**. El diseño se centra en la organización de contenidos, el uso de Flexbox para la maquetación y la integración de elementos multimedia.

## 🛠️ Tecnologías Aplicadas
* **HTML5 Semántico:** Uso de etiquetas como `header`, `nav`, `main`, `section`, `article` y `footer`.
* **CSS3 Flexbox:** Implementación de layouts flexibles para la navegación, el portafolio y los bloques de contenido.
* **SEO & Metadatos:** Configuración de etiquetas meta, Open Graph para redes sociales y favicon.
* **Tipografía Personalizada:** Uso de `@font-face` para cargar fuentes locales (`UnifrakturCook-Bold.ttf`).
* **Multimedia:** Inserción de video nativo, imágenes de diversos formatos y mapas interactivos mediante `iframes`.

---

## 📐 Especificaciones de Diseño
* **Contenedor Principal:** 600px de ancho, centrado automáticamente.
* **Paleta de Colores:**
    - Fondo de página: `#FFF5EE` (SeaShell)
    - Títulos: `#90EE90` (Light Green)
    - Botones Navegación: `#0e250e` (Fondo) y `#228B22` (Hover).
* **Efectos:** Inversión de dirección en bloques (`flex-direction: row-reverse`) para crear un flujo visual dinámico.

## 🚀 Cómo ejecutar la prueba
1. Descarga todos los archivos en la misma carpeta.
2. Asegúrate de que los nombres de las imágenes y videos coincidan exactamente con el código.
3. Abre el archivo `index.html` en tu navegador preferido.
